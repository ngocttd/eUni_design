Nguyên tắc nội dung khối công khai

  • Trang hub / tổng quan là dashboard: số liệu tổng hợp + nội dung nổi bật (chương trình, đối tác, đề tài, sự kiện cụ thể) + tin tức. Không lặp lại danh sách của menu trái dưới dạng lưới ô.
  • Các trang khối "Sinh viên" và "Giảng viên / Cán bộ" công khai là trang thông tin chung, không phải dashboard cá nhân — dữ liệu cá nhân nằm sau đăng nhập ở My eUni Portal.
  • Khi có wireframe mới cho một khối: chỉ đổi bố cục / style component, giữ nguyên mọi route, luồng và dữ liệu đã có.

Chữ

  • Font hệ thống (system-ui). Cỡ gốc 15–16px, line-height 1.5–1.75.
  • Tiêu đề trang h1 ≈ 25px navy; tiêu đề panel ≈ 15px navy IN HOA nhẹ (letter-spacing 0.02em); nhãn eyebrow ≈ 10.5–12px IN HOA, letter-spacing 0.07–0.09em.
  • Số liệu lớn (StatRow): 23–24px, font-weight 800, navy; nhãn 12px, chữ phụ.
  • Số trong bảng & cột căn phải: font-variant-numeric: tabular-nums.

Icon

Bộ icon nội tuyến src/lib/Icon.jsx — stroke ~1.75, 24×24, currentColor, không phụ thuộc thư viện ngoài. Dùng: <Icon name="calendar" size={18} />. Style mockup: icon line navy, đặt trong "chip" nền xanh nhạt bo tròn/bo góc (background:#eef3fb; color: var(--humg-primary)). Tên hợp lệ gồm: home building book flask handshake heart library user users graduation calendar clock file download external eye search shield target rocket globe layers grid newspaper phone mail play headphones award briefcase check menu lock image compass microsoft facebook youtube linkedin zalo và các tên có dấu gạch nối phải để trong ngoặc kép: "arrow-right" "arrow-left" "chevron-down" "chevron-right" "chevron-left" "map-pin".

§3

Khung trang & layout

Header công khai components/layout/Header

  • Thanh tiện ích trên cùng (36px): liên kết nhanh + chuyển ngữ VI/EN + nút "Đăng nhập eUni".
  • Hàng chính (72px): logo 60 năm + wordmark; 5 menu có dropdown (Giới thiệu HUMG, Học tập, Nghiên cứu, Hợp tác, Đời sống) + 3 link nhanh (Thư viện, Sinh viên, Giảng viên / Cán bộ) + tìm kiếm + nút "Đăng nhập eUni".
  • Mobile: gộp thành drawer trượt, đầy đủ 11 khối + Trang chủ + Phụ huynh + Lãnh đạo.
  • Nguồn menu: src/routes/sitemap.js → headerNav (suy ra từ mainNav).

Footer components/layout/Footer

Nền navy, lưới 4 cột 1.7fr 1fr 1fr 1.15fr, max-width 1400px, gap 40×56. Cột 1: logo + địa chỉ + điện thoại + email. Cột 2–4: footerColumns (Liên kết nhanh, Chính sách & quy định, Kết nối). Hàng dưới: bản quyền + link app + QR. Responsive: 3 cột (≤1080), 2 cột (≤720), 1 cột (≤480).

§5

Đặc tả trang công khai

Mỗi khối = một section-nav + một trang hub + các trang chi tiết. Trang chi tiết đều dùng PageShell với biến thể --nav --aside (menu khối trái, nội dung giữa, sidebar phải).

Trang chủ /

  • Hero: ảnh /brand/hero-campus.jpg phủ toàn chiều rộng + lớp phủ sáng trái; nội dung: "60 NĂM", tiêu đề slide, "1966 – 2026", motto, chips, 2 nút, slider dots. Data: heroSlides, heroChips.
  • QuickBar: 8 lối tắt (quickLinks) — Lịch công tác, Thư viện số, E-learning, Tra cứu tuyển sinh, Biểu mẫu, Webmail, Tiện ích khác, Liên hệ.
  • Dành cho bạn: 6 thẻ đối tượng (audiences) — Thí sinh, Sinh viên, Phụ huynh, Cựu sinh viên, Giảng viên, Đối tác; mỗi thẻ màu riêng + ảnh.
  • Thế mạnh: strengths (4 mục). Tin – Sự kiện – Media: featuredNews, newsList, upcomingEvents, mediaTabs. Đối tác: partners.

Giới thiệu HUMG /gioi-thieu

  • Cơ cấu tổ chức: sơ đồ + lưới "Các khối đơn vị" dẫn tới: Ban Giám hiệu, Khoa / Viện, Phòng / Ban, Trung tâm / Viện, Đơn vị trực thuộc, Đội ngũ, Danh sách chuyên gia.

§9

Bàn giao & quy ước

Chuyển mock → API

  • Data hiện ở src/data/*.js (mỗi khối một file). Thay bằng lớp src/api/*.ts gọi endpoint tương ứng (§8) + hook useQuery; giữ nguyên hình dạng object để component không phải sửa.
  • Component UI (components/ui/page.jsx) không gọi API — trang (pages/*/index.jsx) nạp data rồi truyền xuống props.
  • Placeholder humg-ph → <img> khi có URL media; giữ đúng data-ratio.

Trạng thái tải & lỗi

  • Skeleton theo hình dạng component (Panel, StatRow, bảng) — không spinner toàn trang.
  • Lỗi tải khối: hộp thông báo trong Panel + nút "Thử lại"; không làm hỏng cả trang.
  • Danh sách rỗng sau lọc: dòng "Không tìm thấy… phù hợp" (đã có ở FilterBar).
  • Form: xác thực phía client + hiển thị lỗi từng trường; toast "Đã gửi" khi thành công.

Route & SEO

  • Nguồn route: src/routes/sitemap.js (publicRoutes = collectFromNav() + standalonePublic + detailPublic). Khi bỏ mục khỏi menu vẫn phải giữ route (chuyển sang standalonePublic).
  • Mỗi trang set <title>, meta description, canonical, OpenGraph từ dữ liệu API.
  • Cân nhắc SSR/prerender cho các trang nội dung (tin tức, giới thiệu, chương trình) để SEO.

Quy ước code

  • CSS: dùng token --humg-*, không hardcode màu; class theo BEM nhẹ (.block__el, .is-active).
  • Icon: chỉ dùng tên có trong Icon.jsx (§2); tên có gạch nối để trong ngoặc kép.
  • FilterBar.sortOptions nhận mảng chuỗi. Pagination hiện chỉ hiển thị — nối handler khi có API phân trang.
  • Build: npm run build (Vite). Kiểm tra link chết trước khi bàn giao.
